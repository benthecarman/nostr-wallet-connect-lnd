# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in arkzap-me, please email
[benthecarman@live.com](mailto:benthecarman@live.com).

Include a description of the issue, steps to reproduce it, its potential impact,
and any suggested remediation. Please do not open a public issue or disclose the
vulnerability publicly until it has been investigated and a fix is available.

You will receive an acknowledgment as soon as practical, followed by updates as
the report is investigated.
